# Starter Templates

This folder contains runnable Dock-Host starter templates that demonstrate how to organize code under `app/...`.

## Included templates

- [`node-app/`](node-app) — Node.js example with `app/index.js` and a helper module in `app/message.js`
- [`python-app/`](python-app) — Flask example with `app/app.py` and a helper module in `app/config.py`

These templates are intended as simple starting points for deployments from GitHub or the Dock-Host CLI.
